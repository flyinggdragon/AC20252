# AudioSpectrum:
O aplicativo possui uma cena, onde toca uma música. Os cubos atrás representama s 8 bandas de áudio. A coluna vermelha representa o volume, que aqui é composto pela soma das 8 bandas, dividido por 2f para caber em tela.
A animação do personagem varia conforme a intensidade da música, definida pela soma das bandas, dividido por 2.2f.

<-/-> - Selecionar músicas.
